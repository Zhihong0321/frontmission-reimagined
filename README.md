# Mecha Trader

Overland trading in the shape of *大航海時代IV*: read a market, plan a route, haul cargo,
live off the margin. Trucks instead of ships, Europe instead of the ocean, mech-industry
commodities instead of spices. **No combat.**

**Version:** `0.5.0-alpha` (the one-line `VERSION` file at the root).

**World canon:** [LORE.md](LORE.md) — *the Hush*, post-invasion Europe.

Target is a Steam release. Stack today is .NET 8 plus a browser view; the intended end
state is a Godot 4 (C#) client over the same simulation library.

## Play

Double-click **`Install-Launcher.cmd`** once to put a **Mecha Trader** shortcut on the
desktop. Play from there, or double-click **`Play.cmd`**. That rebuilds, starts the
server, and opens **Keeper's Chart** at <http://localhost:5080/chart/>. Close the
launcher window to stop.

`/` redirects to `/chart/`. There is no `demo-map.html`.

| On the chart | What it does |
|---|---|
| W A S D | drive. Release coasts; it does not halt. |
| click | Core pathfinds to that cell. Click again to reroute. |
| arrows / drag / wheel | pan and zoom |
| space / 1 2 3 / F / H | pause, pace, follow, whole chart |
| Tab / Esc | open and close the ops shell (the rail on the left opens a page directly) |

| In the shell | What it does |
|---|---|
| Overview | credits, net worth, burn, hold, crew; where you are; cargo valued at the local offer; roads out |
| City | Market (click a row → buy/sell pane; locked grades greyed), Relationship (segments, grades, permits, favor), City stats, Roads (Load best / Depart), Recruitment, Station (sell / fit / buy trucks, gear), Contracts (board + held), Expo (pass, stall asks, the hall), Storeroom, Wire |
| Caravan | hold, speed, burn, trucks with fittings, gear, mining; cargo; contracts held; what the crew does for the convoy |
| Crew | posts (Trading, Information: who leads, how many hands, what the informant reaches); roster with a post picker → click a name for the character sheet (post, skills, knowledge, traits, dismiss); recruitment board → sheet → hire |
| Ledger | every entry on the books, filtered by kind; which build is running |
| Pass N days | in the shell header, while parked. On the road the chart passes days itself. |

## Architecture

**The simulation is a standalone library. Every front-end is a view over it.**

The chart talks to Core over JSON. A Godot scene will call the same library in-process.
Neither is allowed to own a rule. That is enforced by a test, not by discipline.

```
Command  →  CommandProcessor  →  GameState  →  ViewBuilder  →  GameView  →  JSON  →  chart
                ↑
            DayTick (markets, costs, travel, solvency)
```

Time advances only through `WaitCommand`. `Depart` starts (or reroutes) a journey and
spends no days itself. WASD and click on the chart issue `depart` to a cell; the chart
then posts `wait 1` as days elapse.

State changes only through `CommandProcessor`. Seed + command list ⇒ identical state.

## What Core already does

A city holds each good in two stores: a **shelf** you buy from, and an **intake** that
takes what you sell. Unloading never cheapens the shelf. Buy price reads the shelf, sell
price reads shelf + intake, so sell can never beat buy.

Cities are founded with vitals in `cities.json`; live values live in the save. Supply
figures are derived from the market, never stored. Standing is a number per city; rank
and reserved shelf are reads of that number. Events overlay price and vitals; a stock
shock writes once.

Travel is cell-to-cell on the painted grid, not city-to-city only. `Depart` accepts a
city id, a mining claim id, or a cell id `"col,row"`. Issuing it while already moving
reroutes from the current cell.

Crew: four seats, skills led by the best hand aboard, category knowledge, optional
traits. Recruitment pools are derived from `(seed, city, round)` and never stored.

Products come in five grades. A city will not sell its higher grades to a stranger; the
lock reads total standing across four segments (governor, citizens, traders, one held
back). What a city makes grades by its craft, and the shop charges for the grade you
pick. Contract boards and expo calendars are derived from the seed like recruitment
pools; only acceptances, passes and asks are state. A city's own produce is never
allowed on a stall at its own expo.
